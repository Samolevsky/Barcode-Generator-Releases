# Barcode Generator

Create and scan barcodes with customizable appearance and PNG/SVG export. [Product and support](https://samolevsky.com/).

## Download

**[Download the latest version](https://github.com/Samolevsky/Barcode-Generator-Releases/releases/latest)**

| Platform | File to choose on the latest release |
| --- | --- |
| macOS — Apple Silicon (M-series) | `*-mac-arm64.dmg` |
| macOS — Intel | `*-mac-intel.dmg` |
| Windows — x64 | `*-win-x64.exe` |

The `.zip`, `.blockmap`, and `.yml` files support the in-app updater; download the DMG or EXE for a manual installation. Hyphenated ZIP/EXE aliases are provided for updater compatibility.

## Updating

- **Version 0.2.3 has no updater.** When an updater-enabled version is released, download its installer here and install it manually over the old copy.
- **Starting with version 0.2.4:** Check for Updates is in the macOS application menu or Windows Help menu. The app also checks shortly after launch, asks before downloading a newer version, and offers restart/install when ready. If you choose Later, the downloaded update installs when you quit.
- Normal updates retain your presets, preferences, and license. Keep a backup of important presets.
- If updating fails, download the latest installer from this repository.

Version 0.2.4 is available now. Its macOS builds are Developer ID signed and notarized, with validated stapled tickets. Windows installers remain unsigned and may trigger SmartScreen warnings. Earlier 0.2.3 installers are unsigned and not notarized. Read each release's notes for its verification status.
